## ✅ 6. Create and Assign a Policy at Subscription Level

### 🔹 Objective:
Create a policy definition that audits virtual machines not using managed disks and assign it at the subscription level.

---

### 🔹 Step 1: Create Policy Rule File

Save the following as `rules.json`:

```json
{
  "if": {
    "allOf": [
      {
        "field": "type",
        "equals": "Microsoft.Compute/virtualMachines"
      },
      {
        "field": "Microsoft.Compute/virtualMachines/storageProfile.osDisk.managedDisk.id",
        "exists": "false"
      }
    ]
  },
  "then": {
    "effect": "audit"
  }
}
